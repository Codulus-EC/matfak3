# Математический факультет ВГУ — редизайн сайта

Учебный/проектный редизайн сайта математического факультета ВГУ. Проект собран на **Next.js + React + TypeScript** и содержит главную страницу, раздел для школьников и архив олимпиадных материалов.

## Что уже есть

- крупный hero и адаптивная навигация;
- блок «Почему выбирают Матфак?»;
- программы обучения с переключением уровней;
- события и FAQ;
- контакты и карта;
- отдельная страница **«Школьникам»**;
- региональная олимпиада и школа олимпиадной математики;
- расписание занятий;
- архив примеров/решений задач;
- архив результатов прошлых лет;
- отдельный маршрут архива задач.

## Маршруты

- `/` — главная;
- `/schoolchildren` — школьникам;
- `/schoolchildren/tasks` — архив задач и решений.

## Стек

- Next.js 15
- React 19
- TypeScript
- CSS Modules + глобальные CSS-стили

## Локальный запуск

Нужен **Node.js 20+**.

```bash
cd frontend
npm install
npm run dev
```

После запуска откройте:

```text
http://localhost:3000
```

На Windows также можно запустить `START_SITE.bat` из корня репозитория.

## Проверка перед публикацией

```bash
cd frontend
npm ci
npm run typecheck
npm run build
```

## Публикация на GitHub Pages

Проект подготовлен для **GitHub Pages** через GitHub Actions. При каждом push в `main` или `master` workflow:

1. устанавливает зависимости;
2. запускает TypeScript-проверку;
3. собирает статический Next.js export в `frontend/out`;
4. автоматически подставляет корректный `basePath` GitHub Pages;
5. публикует сайт через официальный `actions/deploy-pages`.

После первой загрузки репозитория:

1. Откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь успешного workflow `Deploy Next.js site to GitHub Pages`.
4. Ссылка на опубликованный сайт появится в deployment и в **Settings → Pages**.

Локально `basePath` пустой, поэтому обычный `npm run dev` продолжает работать на `http://localhost:3000`.

## Структура

```text
.
├── frontend/
│   ├── app/                 # маршруты Next.js и глобальные стили
│   ├── components/          # компоненты интерфейса
│   ├── lib/                 # данные и вспомогательная логика
│   ├── public/              # изображения и статические ресурсы
│   ├── package.json
│   └── package-lock.json
├── backend/                 # заготовка под будущий REST API
├── .github/workflows/deploy-pages.yml # проверка + автоматический deploy на GitHub Pages
├── .gitignore
├── START_SITE.bat
└── start-site.sh
```

## Backend

Текущая версия проекта ориентирована на frontend. Папка `backend/` оставлена как заготовка для следующего этапа: REST API, новости, программы, документы, результаты, расписание и контакты.
